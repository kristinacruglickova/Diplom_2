# API-тесты Stellar Burgers

Проект автоматизации API-тестирования для Stellar Burgers.

## Стек технологий

| Компонент | Версия |
| --- | --- |
| Java | 11 |
| Maven | 3.9.x |
| JUnit | 4.13.2 |
| Rest Assured | 5.5.1 |
| Allure | 2.29.1 |
| Lombok | 1.18.30 |

## Структура проекта

- `src/test/java` — тесты, API-клиенты, модели, утилиты
- `src/main/java` — общие исходные файлы (например, эндпоинты)
- `target/allure-results` — «сырые» результаты Allure после запуска тестов

## Подготовка

Убедитесь, что у вас:

- установлен JDK 11
- установлен Maven
- есть доступ к тестируемому API

## Запуск тестов

```bash
mvn clean test
